## Getting Started/Using

1. Clone or download the repository
2. Unzip if needed and open the repository in your own VS Code or Preferred ng Editor.
3. cd into the NoSudoku folder

	```cd /NoSudoku```
4. Proceed to Installing & Running

### Installing & Running

5. Use the command 

	```npm install```
6. For running in just the web browser use the following command

	```npx expo start```
OR

7. For using on Expo Go and browser use the following command

	npx expo start --tunnel

8. There might be an error for this if Ngrok is not installed. To install that if needed you can use the following command 

	npm install Ngrok


## Reflections && Design Choices

### Troy Berhow

### Jay Rudel
	Working on this project has been lots of fun. My group mates were a ton of fun to work with, one of my favorite parts about my group is that we had such strong communication throughout the entire project. Made it super simple to get stuff done and turn things in on time. One of my favorite parts about this project was actually learning more about different tabs. Troy for his camera project made multiple tabs and I did not, I was confused originally to how it worked but after working with Troy and them. I understand them better and I think they are an awesome tool. 

	One of the design choices that I faced was actually the generator for the puzzles themselves. I separated the logic out like I did in my personal project that I was working on in java. I thought it made sense to kind of compare the logic between the two and build from there. While it is different because Java and JS are built differently they are similar which makes it easy to do. One of the other design choices I faced was actually the timer. I originally had the timer be its own file, but then when the game was completed I had no real way to stop the timer so even though the board itself froze and didn't allow you to change the timer still kept going and I didn't like that. On the same page, the other design choice I had freedom over was, if the board once it was completed what happened. I made it so any time the board gets completed the board and timer then stop so people can’t change the numbers from there.
